# 마음장부 카운터 3.0 — 축의금 접수·계수 프로그램

결혼식(경조사) 접수대에서 **봉투 속 현금을 정확하게 세고, 장부와 실제 현금을 대조해 마감**하기 위한 프로그램입니다.

기존 v2.0.0은 Windows 전용 exe였지만, 3.0은 **`index.html` 파일 하나**로 동작하는 오프라인 웹앱입니다.
설치가 필요 없고, 접수대의 노트북·태블릿 어디서든 브라우저로 열면 바로 쓸 수 있습니다. 인터넷 연결도 필요 없습니다.

## 사용 방법

`index.html`을 더블클릭해 브라우저(크롬·엣지 권장)로 열면 끝입니다.

화면은 실제 접수대 업무 순서 그대로 4단계입니다.

| 단계 | 하는 일 |
|---|---|
| **1 접수 (1차 카운팅)** | 봉투를 열고 5만·1만·5천·1천원권 장수와 동전·수표·기타 금액을 입력. 이름·소속·봉투 표시·메모·식권 지급·답례품 여부도 함께 기록. 저장하면 봉투 번호가 부여됩니다 — **봉투에 같은 번호를 적어 두세요.** |
| **2 2차 검수** | 1차 금액을 **숨긴 채** 같은 돈을 다시 셉니다. 권종별 장수까지 전부 일치해야 검수 완료. 불일치면 해당 봉투만 남겨 다시 확인합니다. |
| **3 마감·정산** | 전체 현금을 권종별로 세서 입력하면 장부와 자동 대조. 미검수·불일치 0개 + 차액 0원일 때만 마감됩니다. CSV 정산표 저장·인쇄, 새 행사 시작. |
| **4 전체 기록·설정** | 통계, 식권 관리(잔여 자동 계산·대여 기록), 전체 기록 검색, 수정·취소·복구, JSON 백업/복원, 행사명 설정. |

### 단축키

- <kbd>F1</kbd>~<kbd>F4</kbd> : 5만·1만·5천·1천원권 한 장씩 추가 (접수·검수 탭)
- <kbd>Enter</kbd> : 저장하고 다음 봉투 / 검수 대조
- <kbd>Esc</kbd> : 입력 지우기 / 다시 세기

## v2.0.0 → 3.0 개선 내역

실제 축의금 접수 경험담([참고 글](https://m.blog.naver.com/dynamic_dy/223473833183))에서 나온 문제들을 반영했습니다.

| 접수 현장의 문제 (경험담) | 3.0의 해결 |
|---|---|
| 봉투 번호를 안 적어 누락 발생 | 저장 시 봉투 번호 자동 부여 + "봉투에 번호를 적어 두세요" 안내 (v2에도 있던 핵심 기능 유지) |
| 장부보다 실제 현금이 20만원 많았는데 누가 냈는지 확인 불가 | 봉투별 블라인드 2차 검수 + 마감 시 권종별 대조로 차액이 **어느 봉투에서 생겼는지 추적 가능** |
| 식권 부족·반대측에서 빌려오기, 빌려준 걸 잊음 | **식권 관리 신설** — 준비 수량, 봉투별 지급 수량, ±조정 기록("신랑측에 빌려줌 -20"), 잔여 자동 계산, 부족 경고 |
| 식사 안 하는 분께 답례봉투 지급 | 봉투별 **답례품·답례봉투 지급 체크** 및 집계 |
| 빈 봉투를 내는 경우 | 0원 봉투도 확인 후 **"빈 봉투"로 기록** 가능 (v2는 저장 불가였음) |
| 한자 성함, 특이사항을 종이에 메모 | 봉투별 **메모 입력란** 신설, 검색 가능 |
| 정신없는 현장에서 이름·번호 찾기 | 이름·소속·봉투 표시·메모·번호 **통합 검색** 신설 |
| Windows PC에서만 사용 가능 | 브라우저만 있으면 어디서나 (태블릿 포함, 오프라인 동작) |

v2.0.0의 기능은 전부 유지했습니다: 3단계 워크플로우, 권종별 카운팅과 자동 합계, F1~F4·Enter·Esc 단축키,
블라인드 2차 검수(일치 시 자동 다음, 불일치 시 1·2차 내역 비교), 권종별 마감 대조와 마감 잠금,
CSV 정산표, 새 행사 시작(기존 장부 보관), 저장 실패·손상 복구 안내 문구까지 동일한 흐름입니다.

## 데이터 저장과 백업

- 입력 즉시 브라우저 저장소(localStorage)에 자동 저장되며, 직전 상태의 백업본을 함께 유지합니다.
  원본이 손상되면 자동으로 백업본으로 복구합니다.
- **같은 브라우저·같은 컴퓨터**에 저장됩니다. 행사가 끝나면 반드시
  **[CSV 정산표 저장]**과 **[JSON 백업 내려받기]**로 파일 사본을 남겨 두세요.
- [새 행사 시작]을 누르면 기존 장부가 JSON 파일로 내려받아지고, 브라우저 안 보관함에도 남습니다(최근 5개).
- JSON 백업은 [JSON 백업 불러오기]로 언제든 복원할 수 있습니다.

## 개발

```

├── index.html     # 앱 전체 (의존성 없는 단일 파일)
├── tests/e2e.mjs  # Playwright 스모크 테스트 (47개 검증)
```

테스트 실행:

```bash
npm install playwright   # 크로미움 포함
node tests/e2e.mjs
```
